# ANIVIBES
Сайт для подбора аниме на вечер — по предпочтениям, настроению или воле случая.

# О проекте 
Проект помогает сократить время на поиски и выбрать, что посмотреть, исходя из своих предпочтений и настроения.

Не знаете, с чего начать? Доверьтесь случайному подбору и откройте для себя новое аниме. А если хочется чего-то определённого, настройте фильтры по жанру, типу, настроению и длительности.

# Возможности
- Подбор случайного аниме для тех, кому сложно определиться.
- Фильтрация по предпочтениям и доступному времени.
- Просмотр каталога аниме.
- Знакомство с описанием и основной информацией о выбранном тайтле.

# Стек 
- HTML;
- CSS;
- JavaScript

# Дальнейшее развитие
После реализации основных возможностей планируется:

- Отображение рейтингов из внешних источников в карточках аниме.
- Регистрация и личный кабинет пользователя.
- Добавление аниме в избранное.
- Создание личных подборок.
- Отслеживание прогресса просмотра и статистики.
- Пользовательские оценки и внутренний рейтинг.
- Комментарии к аниме.
