# anivibes

Сайт по подбору аниме на вечер. Проект помогает сократить время на поиски и выбрать, что посмотреть, исходя из своих предпочтений и настроения.

Не знаете, с чего начать? Доверьтесь случайному подбору и откройте для себя новое аниме. А если хочется чего-то определённого, настройте фильтры по жанру, типу, настроению и длительности.

# Возможности:
- Подбор случайного аниме для тех, кому сложно определиться.
- Фильтрация по предпочтениям и доступному времени.
- Просмотр каталога аниме.
- Знакомство с описанием и основной информацией о выбранном тайтле.
